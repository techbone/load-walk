# Recording guide (clips 2 to 6)

One clip at a time. Each starts from a fresh state: **reset the preview camera, refresh, check the Logger shows "Lens has been reset" once, then press record.** Preview set to **Evening Room**, device **SPECS 27**. Speakers on, headphones off. Cmd+Shift+5 → Record Selected Portion around the preview, Options → Microphone: your Mac mic.

Say the lines in your own words; they're a guide, not a script to read. Pause when something is happening on screen, and let the chip and meter be on screen for a second before you talk over them.

Name the files `01-story.mov`, `02-freezer.mov`, … so they join in order.

Do the setup off-camera first (marked **Before recording**), then start recording.

## If something goes wrong

- **Voice doesn't respond:** toggle the preview's microphone icon off and on, make sure the Lens's Voice toggle is on, say the phrase, and wait a second or two after. If it still fails, record the clip with a click instead and don't mention voice.
- **No chime in the recording:** speakers on, volume up, headphones off.
- **Two "Lens has been reset" lines:** refresh again before recording.
- **A card or tag opens in a bad spot:** reset the camera, refresh, try again.
- **Over 3 minutes in total:** drop the optional voice beat in clip 2 and the "favourite bug" story.
