# Demo script (under 3:00)

Recorded from Lens Studio's Interactive Preview. Real runs only; nothing sped up. If a voice line needs repeating, leave it in or redo the take.

Thesis: **Look around your house, see what your inverter can carry.**

## Before every take

1. Reset the preview camera, then refresh the preview (the room places itself where the camera is when the Lens starts).
2. Check the Logger shows "Lens has been reset" only once. If twice, refresh again.
3. Speakers on, no headphones (the mic picks up the chime). Preview mic off until the voice beats.
4. Cmd+Shift+5 → Record Selected Portion around the preview, Options → Microphone: your Mac mic.
